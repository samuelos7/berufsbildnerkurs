Meine Rolle als Berufsbildner/in
Praxisbezug
Als baldige Berufsbildner/innen begleiten Sie Lernende in der Ausbildung. Dies ist eine spannende und facettenreiche Aufgabe. Damit setzen Sie sich in dieser Aufgabe auseinander.

Rahmenbedingungen
- Tandems
- 30 Minuten

Was ist zu tun?
- Verschiedene Bereiche beeinflussen Ihren Arbeitsalltag als Berufsbildner/in. Gehen Sie die folgenden Bereiche durch und besprechen Sie, was Sie bereits dazu wissen:

| Bereiche/Fragen | Überlegungen dazu (stichwortartig) |
| --- | --- |
| Die Entwicklung und die Beurteilung/Standortbestimmung als Zentrum Ihrer Arbeit. |  |
| Die Vorbereitung der Lern- und Arbeitsumgebung | Erste Woche ist massgebend für Zukunft Erste Arbeitstag muss geplant sein (präsent sein) |
| Die Rekrutierung von Lernenden | Arbeitsweg Schulische Leistungen (optional) !Schnupperlehre mit Aussicht Bewerbungsgespräch Charakter/Lernfähigkeit Passt Frau in Männerberuf |
| Die Beziehungsgestaltung mit Lernenden | Nicht strenger Berufsbildner/Chef Gleich Respekt (z.B. auch bei Tochter von Kollegen) Respekt beibringen!! Nicht Arbeit belächeln |
| Die Kommunikation mit allen Anspruchsgruppen | Amt, Trainer, Therapeuten, Eltern, andere MA Wird nicht immer alles regelkonform laufen Beurteilungsgespräch ohne Eltern |
| Thema Gleichstellung/Gleichberechtigung und die Haltung des Lehrbetriebs |  |
| Die Unterstützung für weitere Schritte im Arbeitsleben (z.B. Bewerbungen) | Zeit für Lernende geben -> wird ja investement Ük kann auch Arbeitszeit verlangen? |









- Beantworten Sie folgende Fragen und halten Sie beide Ihre Überlegungen stichwortartig fest:

| Bereiche/Fragen | Überlegungen dazu (stichwortartig) |
| --- | --- |
| Welche Erwartungen gibt es von Ihrer Firma an Sie als Berufsbildner/in? | Lehrlingswesen ausbessern |
| Welche Erwartungen haben Sie an sich selbst als Berufsbildner/in? | Führungsstil finden |
| Wann gibt es Konflikte zwischen den Berufsbildner/innen und Vorgesetzten? |  |
| In welchen Rollen werden Sie als Berufsbildner/in gebraucht? | An erster Augustwoche Anwesend Seelsorger Koordinator |
